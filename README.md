## Featured Projects

### 💬 JustChat (Real-Time Chat Application)
*Architecting low-latency communication networks*

**Vision**
Build a highly responsive messaging platform where conversation history retrieval and real-time syncing happen seamlessly.

**What it does**
A full-stack chat application that handles secure user authentication, media sharing, and instant messaging with a low ~75ms round-trip latency.

**How it's built**
* ⚡ **Real-time Engine:** WebSocket communication powered by **Socket.io** and **Node.js**
* 🗄️ **Data Persistence:** **MongoDB** with optimized schemas for fast message retrieval
* 🐳 **Infrastructure:** Containerized with **Docker** and deployed on Render for scalable conversation threading
* 🔐 **Security:** Integrated Clerk for authentication and ImageKit for secure media sharing
